# Task 01 — Complete `same-picture` vertical slice

## Goal

Implement one production-quality game from parent entry through session end. Do not build a broad but shallow catalog UI.

## Functional path

1. Parent gate.
2. Anonymous local profile or optional local display name.
3. Session settings: 5–7 minute default, audio, music, reduced motion, target size.
4. Child home with one large activity.
5. Short visual/audio demonstration.
6. Deterministic `same-picture` level generated by seed.
7. Pure state reducer and evaluator.
8. Neutral error feedback, two graded hints and one-axis simplification.
9. Local attempt event and mastery update.
10. Calm completion and offline transfer prompt.
11. Session cap returns control to adult; no child-mode continuation button.
12. Parent can export and delete local data.

## Content

Use:

- `content/game-catalog.json` → `same-picture`;
- `content/level-ladders.json` → reference difficulty anchors;
- `content/themes/sample-items.json` → placeholder semantic content;
- `packages/core` → generation, mastery and adaptation.

Artwork and audio may be placeholders, but IDs and licenses must be explicit.

## Tests

- same seed + difficulty + content pack produces the same level;
- exactly one correct answer;
- choices never duplicate IDs;
- accessibility labels identify all actions;
- touch targets meet the child UX minimum;
- first, second and third errors follow the support ladder;
- distress/abandon does not lower mastery;
- app completes the flow offline;
- parent gate resists back-navigation bypass;
- local deletion removes profile, attempts and creations.

## Exit gate

No additional game may be implemented until this vertical slice passes logic, accessibility, privacy, persistence and end-to-end tests.
